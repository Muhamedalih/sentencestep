# استوديو صوت SentenceStep (VoiceStudio المحلي ← الموقع)

## التشغيل

1. افتح برنامج **VoiceStudio** (يجب أن يبقى مفتوحاً).
2. اضغط الاختصار على سطح المكتب **«SentenceStep Voice Studio»** (أو: `npm run voice:panel` داخل `C:\Looma`).
3. تفتح صفحة `http://127.0.0.1:4410` في المتصفح.

## الاستخدام (4 خطوات في الصفحة)

1. **اختر الدرس** (ابحث برقمه أو عنوانه؛ الدروس العادية والقصص كلاها هنا).
2. **اختر الصوت**. لإضافة صوت جديد: احفظه أولاً في VoiceStudio (استنساخ أو تصميم)، ثم افتح «إضافة صوت جديد»، اختر أنثى/ذكر، واضغط «أضفه للموقع».
3. **ابدأ التوليد**: يصنع كل جملة وكل كلمة وحدها، ويفحص كل مقطع بإعادته إلى نص، ويعيد المحاولة تلقائياً إذا كان خاطئاً. يمكنك الاستماع لكل مقطع وإعادة أي واحد («أعد»).
4. **استخدم هذا الصوت في الدرس**: تغيّر صوت الدرس فعلاً. لا تعمل إلا إذا كانت **كل** مقاطع الدرس جاهزة، وتحفظ الصوت السابق ويمكنك «تراجع».

## ما الذي يغيّره كل شيء؟

- الخطوة 3 تضيف مقاطع جديدة فقط (لا تلمس أي صوت قديم ولا أي درس). لا أحد يسمعها حتى الخطوة 4.
- الخطوة 4 هي الوحيدة التي يسمعها المتعلمون.

## الأمر النصي (بدل الصفحة)

`npm run voice:fill -- --lesson=normal-5 --voice=voicestudio-bd963f07 [--scope=sentences|words] [--dry]`

## ملاحظات

- الكلمة المفردة تُنطق مع نقطة بعدها («ordered.») لأن الكلمة العارية تتشوه.
- الأصوات تُصنع على جهازك (GPU). حوالي 4 ثوانٍ للكلمة و9 للجملة.
- الكود: `scripts/voice-studio/` (lib.ts النواة، panel.ts الخادم، panel.html الصفحة).
- لم يُدعَم بعد: المقالات (Passages) والكتب (Books)، وكلمات القصص المستهدفة (story-vocab).
